# BidMyTicket 🎟️

A premium black-and-gold ticket auction marketplace **demo** built with Next.js.

> This is a learning/prototype project. Listings and bids are fictitious, held in the browser, and do not represent real ticket transfers or payments.

## Run in GitHub Codespaces (no downloads)

1. Open this repository on GitHub.
2. Select **Code → Codespaces → Create codespace on main**.
3. In the cloud terminal, run `npm install`, then `npm run dev`.
4. Open the forwarded port `3000` in your browser.

## Upcoming functionality

Explore tickets, demo auctions and bidding, ticket listing forms, dashboard, login/sign-up demo screens, provider eligibility notices, mobile responsive design.

Real money, real tickets, and real users are intentionally **not enabled** in this prototype.
