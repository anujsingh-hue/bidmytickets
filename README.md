# BidMyTicket

Event ticket auction presentation sandbox. Fictional event listings, 80% starting prices and 120% maximum prices, rounded inward to whole rupees and subject to organizer permission, a pre-signed-in local member account and a sample sign-in flow. Any name with at least five letters and any sample password with five or more characters works. Passwords are never stored or transmitted. Bids and the account live in browser memory only; no Supabase, auth server, payment processing, or real ticket transfers. Use sample credentials only.

Live: https://bidmyticket.vercel.app

Checks: npm run build; npm run test:mobile.
